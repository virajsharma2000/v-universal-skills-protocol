# Universal Skills Protocol (USP)

An open standard for packaging, discovering, loading and executing “Skills” — self-contained capability modules usable by any LLM/agent framework.

## Overview  
The USP enables:  
- Discoverability of skills (metadata registry)  
- Lightweight context loading (minimal metadata first)  
- Composability and chaining of skills  
- Portability across agent platforms  
- Encapsulation of domain workflows, templates and scripts  

Inspired by Claude Skills, which are folders containing instructions, scripts, and resources that enhance Claude's performance in specific work contexts, such as Excel tasks or adhering to brand guidelines. These Skills can be created and deployed across various platforms, allowing organizations to tailor the AI to their workflows.
